# @grainshape/fold

Type-safe class variant resolver for TypeScript. Define component variants as a config object, get back a strongly-typed function that resolves the right class string at runtime.

| Package | Description | npm |
|---|---|---|
| [`@grainshape/fold`](./packages/fold) | Core library, framework-agnostic | [![npm](https://img.shields.io/npm/v/@grainshape/fold)](https://www.npmjs.com/package/@grainshape/fold) |
| [`@grainshape/tw-fold`](./packages/tw-fold) | fold + tailwind-merge | [![npm](https://img.shields.io/npm/v/@grainshape/tw-fold)](https://www.npmjs.com/package/@grainshape/tw-fold) |

---

## Quick start

**Without Tailwind:**
```bash
pnpm add @grainshape/fold
```

**With Tailwind (recommended):**
```bash
pnpm add @grainshape/tw-fold
```

See each package's README for full documentation.
